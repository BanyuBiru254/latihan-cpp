If/Else: Dua pilihan untuk kondisi benar atau salah.
Pernyataan else digunakan bersama if untuk menentukan blok kode yang akan dieksekusi jika kondisi pada if bernilai salah (false).

Tanda Kurung (): Kondisi wajib ditulis di dalam tanda kurung setelah if atau else if.
Kurung Kurawal {}: Bersifat opsional jika isi blok hanya satu baris kode. Namun, wajib digunakan jika isi blok lebih dari satu baris.
Urutan else if: Harus ditulis di bawah if dan di atas else.
Posisi else: Selalu berada di paling akhir sebagai pilihan terakhir (default).

penting harusnya :
1. Pernyataan if 
(Satu Kondisi)Digunakan untuk mengeksekusi blok kode hanya jika kondisi bernilai benar (true). Jika salah, blok diabaikan.
cppif (kondisi) {
    // dijalankan jika kondisi true
}
Contoh:
cppif (totalBelanja > 100000) {
    cout << "Anda mendapat diskon!";
}

2. Pernyataan 
if-else (Dua Pilihan)Digunakan untuk memberikan jalur alternatif jika kondisi pada if bernilai salah (false).
cppif (kondisi) {
    // dijalankan jika kondisi true
} else {
    // dijalankan jika kondisi false
}
Contoh:
cppif (umur >= 17) {
    cout << "Bisa membuat SIM";
} else {
    cout << "Belum cukup umur";
}

Untuk menyusun syarat di dalam tanda kurung (kondisi), Anda akan membutuhkan operator berikut:
    Operator Relasional (Perbandingan):
        == : Sama dengan (contoh: status == 'Y')
        >= : Lebih besar atau sama dengan (contoh: usia >= 17)
        <  : Lebih kecil dari
    Operator Logika (Penggabung Syarat)
        && : Operator DAN (Semua syarat harus bernilai benar).
        || : Operator ATAU (Salah satu syarat benar sudah cukup).

Aturan Penulisan (Sintaks) C++
    Tanda Kurung (): Kondisi wajib ditulis di dalam tanda kurung setelah kata if atau else if.
    Kurung Kurawal {}: Digunakan untuk membungkus blok kode. Jika kode di dalam if hanya satu baris,
    kurung kurawal opsional, tetapi sangat disarankan untuk selalu ditulis agar menghindari bug.
    Titik Koma ;: Jangan pernah menaruh titik koma tepat setelah tanda kurung kondisi, contoh yang salah:
    if(usia >= 17);. Titik koma hanya ditulis di akhir baris pernyataan di dalam kurung kurawal.
